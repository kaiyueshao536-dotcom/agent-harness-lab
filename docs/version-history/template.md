# PN：版本名称

## 版本信息

| 项目 | 内容 |
| --- | --- |
| 发布日期 | YYYY-MM-DD |
| 状态 | 已发布 / 开发中 |
| Commit | `完整 SHA` |
| Tag | `pN-topic` |
| OpenSpec | `openspec/changes/change-name/` |
| 变更规模 | N 个文件，新增 N 行，删除 N 行 |

## 背景与目标

说明这个版本解决的具体问题、触发原因和成功标准。

## 实现内容

按后端、前端、合同、数据、工程治理等有意义的边界记录。每项说明行为变化，而不只是文件名。

## 关键设计决策

记录选择、原因、被放弃的方案和主要权衡。

## 关键文件

列出最能帮助读者理解版本的实现、测试和文档入口。

## 验证结果

记录实际执行的命令、准确通过数量、跳过项和已知环境告警。

## 安全与成本边界

说明用户隔离、敏感数据、外部服务调用和可能产生费用的路径。

## 已知限制

明确这个版本没有解决的问题，以及它们是否进入下一版本。

## 复盘结论

总结该版本带来的工程价值、暴露的问题和下一步依据。

## 查看与回退

```powershell
git fetch --tags origin
git switch --detach pN-topic
```

如需基于旧版本继续开发，应新建分支，不要移动原 Tag：

```powershell
git switch -c codex/review-pN pN-topic
```
